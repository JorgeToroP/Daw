Servidor de aplicaciones

Esta pagina la sirve Tomcat desde dentro de biblioteca.war. Aqui no vive la interfaz: la web la sirve Apache. Tomcat solo ofrece la API JSON:

  • api/estado estado de Tomcat y de MariaDB
  • api/libros todos los libros
  • api/libros?q=tolkien busqueda por texto
  • api/generos generos
  • api/estadisticas estadisticas por genero
