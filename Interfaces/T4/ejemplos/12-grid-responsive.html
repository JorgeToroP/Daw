Qué hace cada línea

      
    

  • minmax(200px, 1fr) Cada columna mide como mínimo 200px y como máximo 1fr (una parte del espacio libre).
    • 

  • repeat(auto-fit, ...) En lugar de un número fijo, "todas las columnas que quepan". Con el contenedor a 420px caben 2; a 650px caben 3; a pantalla completa caben 4 y se estiran.
    • 

  • auto-fill vs auto-fit Con pantalla ancha, auto-fill deja columnas vacías reservadas si sobran huecos; auto-fit las colapsa y estira las tarjetas existentes. Compáralos con el ancho al 100%.
    • 

  • repeat(4, 1fr) Para comparar: cuatro columnas fijas que se aplastan a 420px. Por eso auto-fit es mejor para galerías.
    • 

  • place-items: center Dentro de cada tarjeta usamos grid para centrar el número: es la versión grid del centrado perfecto (en una sola línea).
