grid-template-areas: la página completa dibujada con texto

Le pones nombre a cada zona y luego "dibujas" el layout con texto. Es la forma más legible de maquetar una página: cabecera, menú, contenido, lateral y pie.

Qué hace cada línea

      
    

  • grid-template-columns: 180px 1fr 200px Tres columnas: menú fijo de 180px, contenido flexible y lateral de 200px.
    • 

  • grid-template-rows: 70px 260px 60px Tres filas: cabecera, cuerpo y pie.
    • 

  • grid-template-areas Cada cadena entre comillas es una fila y cada palabra una celda. Repetir un nombre (cab cab cab) hace que esa zona ocupe varias celdas. Las zonas tienen que ser rectangulares.
    • 

  • .cab { grid-area: cab; } El hijo se coloca en la zona con ese nombre. El orden del HTML ya no importa.
    • 

  • .sin-lateral Cambiando solo el dibujo, main main hace que el contenido ocupe también el hueco del lateral.
    • 

  • .movil Una columna y las zonas una debajo de otra. En un proyecto real esto iría dentro de un @media (max-width: 700px).
