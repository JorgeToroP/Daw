Qué hace cada línea

      
    

  • .nav { display: flex; align-items: center } Logo, enlaces y botón en fila y centrados verticalmente aunque tengan tamaños de letra distintos.
    • 

  • .boton { margin-left: auto } El truco más útil de la barra: un margen automático se come todo el espacio libre y empuja el botón al extremo derecho. Pulsa 0 para ver cómo vuelve junto a los enlaces.
    • 

  • .hero { flex-direction: column; align-items: center } Con column el eje principal es vertical y el transversal horizontal. Por eso aquí align-items: center centra en HORIZONTAL.
    • 

  • .tarjeta { flex: 1 } Las tres tarjetas miden lo mismo de ancho.
    • 

  • align-items: stretch Las tres tarjetas tienen la misma altura aunque la verde tenga más texto. Con float esto era casi imposible. Pulsa flex-start para ver la diferencia.
