Qué hace cada línea

      
    

  • flex: 1 Abreviatura de flex-grow: 1; flex-shrink: 1; flex-basis: 0. Traducido: "parte de cero y quédate con 1 parte del espacio". Si los tres tienen 1, son iguales.
    • 

  • flex: 2 en B B se queda con 2 partes y A y C con 1 cada una: B mide el doble. Es una proporción, como las fracciones de una tarta.
    • 

  • flex: 0 0 auto No crece ni encoge: B mide solo lo que necesita su contenido y A y C se reparten el resto.
    • 

  • .menu { width: 200px; flex-shrink: 0 } El menú tiene un ancho fijo y flex-shrink: 0 impide que se encoja si falta espacio.
    • 

  • .contenido { flex: 1 } El contenido se come todo el espacio restante, sea cual sea el ancho de la ventana. Este patrón aparece en casi todas las aplicaciones web.
