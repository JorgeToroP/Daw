Qué hace cada línea

      
    

  • .block { display: block; } El elemento ocupa el 100% del ancho disponible y el siguiente elemento baja a otra línea. Es el valor por defecto de div, p, h1, section...
    • 

  • .inline { display: inline; } El elemento se comporta como una palabra más del texto. Fíjate en que width: 300px y height: 80px no hacen nada: inline los ignora. Es el valor por defecto de span, a, strong.
    • 

  • .inline-block Lo mejor de los dos: se queda en la línea como inline, pero sí respeta ancho, alto y márgenes verticales. Útil para botones o etiquetas.
    • 

  • display: none El elemento desaparece y no ocupa espacio. Pruébalo con la caja rosa: el texto de alrededor se junta.
    • 

  • Idea clave Todo lo que veremos después (flex y grid) son simplemente otros valores de esta misma propiedad display.
